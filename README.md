🚗 Used Car Price Segment Prediction (CarDekho Dataset)

A Data Science & Machine Learning project in Python that predicts whether a used car falls in the Low, Mid or High price segment, using classification models.

Built as part of my B.Tech CSE (Data Science minor) coursework at Lovely Professional University.

📌 Problem Statement

Given the details of a used car (age, km driven, engine, power, fuel, transmission, brand, owner, seller type), predict its price segment. Price is a continuous number, so selling_price is split into 3 equal-sized classes with pd.qcut, which turns this into a 3-class classification problem.

Class	Price range	Cars
Low	up to 3 lakh	2,462
Mid	3 to 5.5 lakh	2,210
High	above 5.5 lakh	2,249
📂 Dataset
Source: Vehicle dataset from CarDekho (Kaggle), file Car details v3.csv
Raw size: 8,128 rows × 13 columns
After cleaning: 6,921 rows
🎯 Objectives

All objectives are investigated with classification models (Logistic Regression, KNN, Naive Bayes, Random Forest).

Which features are the most important for predicting the price class?
How accurately can the models predict the class using only car age and km driven?
How much do fuel type and transmission contribute to the model accuracy?
How much do owner count and seller type contribute to the model accuracy?
Which of the four models is the best classifier?
🔧 Project Workflow
Data cleaning
Removed 1,202 duplicate rows
Converted text columns (mileage, engine, max_power, torque) into numbers and unified torque units (kgm to Nm)
Removed 5 "Test Drive Car" rows
Treated invalid 0 values in engine, power and mileage as missing
Filled missing values (median for numeric columns, mode for seats)
Capped km_driven at the 99th percentile
Feature engineering: brand, car_age, km_per_year, power_per_cc, price_lakh, price_class (target)
Exploratory data analysis: distributions, categorical counts, top brands, correlation heatmap, class-wise charts (24 visualizations in total)
Preprocessing: ordinal mapping (owner), binary mapping (transmission), top-10 brand grouping, one-hot encoding, 80/20 stratified split, StandardScaler fitted on the train set only
Modeling: Logistic Regression, KNN (best K chosen by 5-fold cross-validation), Gaussian Naive Bayes, Random Forest
Evaluation: accuracy, macro precision / recall / F1, cross-validation accuracy, train vs test comparison, confusion matrices, classification report
Objective experiments: models trained on feature subsets and compared against a baseline accuracy
📊 Results
Model	Test Accuracy	Macro F1
Random Forest	0.834	0.832
Logistic Regression	0.820	0.818
KNN (K = 7)	0.787	0.786
Naive Bayes	0.578	0.507
Baseline (always predicting the most common class): 35.6%
Random Forest: train accuracy ~0.99, 5-fold CV accuracy 0.835, test accuracy 0.834. There is some overfitting, but CV and test scores agree.
Naive Bayes performs worst because its feature-independence assumption does not hold (engine, max power and torque are strongly correlated).
The Mid class is the hardest to predict (F1 ~0.74), while Low and High reach ~0.88.
💡 Key Findings
car_age is the most important feature. It has the strongest correlation with the class (-0.64) and the highest Random Forest importance (0.225).
Among cars aged 0-3 years, 66% are in the High class. Among cars older than 10 years, 90% are in the Low class.
Car age alone gives about 62% accuracy, against a 35.6% baseline.
Fuel, transmission, owner count and seller type each carry some signal on their own, but removing them barely changes the full-model accuracy, because their information is largely captured by age, power and engine.

⚠️ Limitations
The data is a snapshot of cars up to the year 2020, so today's market prices may differ.
Price classes are built from quantiles, so cars near a class boundary are misclassified more often.
Missing values were filled with a simple median / mode, calculated on the full data before the split.
Feature-subset results come from a single train-test split (1,385 test cars), so differences of about 1 point should be treated as noise.
